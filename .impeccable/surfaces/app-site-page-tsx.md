## Direction contract

THESIS: The portfolio is a modular signal rack — one built system a visitor can trace signal through. It refuses the dark-dev-portfolio-with-a-grid default: no generic centered hero, no wall of equal project cards, no mono-on-black with a particle field. The one idea it owns: the work is a system, shown as hardware you can patch.

OWN-WORLD: A studio-dark room (#121316) holding brushed-aluminium front panels (#1E2024 faces, #9BA3AD metal) with silkscreen labels and bone legend text (#E8E4D8). Rubber patch cables run in signal-amber (#F2A33C) and patch-cyan (#3FB6C9); jack LEDs glow and breathe. Components are real panel hardware — jacks, knobs, faders, VU meters, patch cables — never stock buttons/cards. Chrome is integer-aligned and pixel-crisp; one SVG geometry drives layout, the cable art, and interactive state together; the active module is marked unmistakably.

STORY: A recruiter or engineer lands facing a powered-on rack that plainly reads "IO — portfolio." Within seconds they grasp that this person builds systems, follow the glowing patch cable to View Work, and reach résumé and contact as clearly-labelled outputs.

FIRST VIEWPORT: The hero is a rack-mounted front panel. Left column: "IO" silkscreened as the module brand, with name and tagline set as panel legend. Real jacks and knobs sit on the face. A patch cable arcs from an INPUT jack to the primary action button "View Work" (the OUTPUT), a luminous pulse travelling it. A status LED reading "Open to SWE roles" breathes top-right. The primary action sits at the cable terminus, unmistakable and obviously clickable.

FORM: analog modular-synth / studio patchbay; position 7 of 7 grounded directions (the assignment); seed:fa4bd18187cdcdf8. Signature interaction: cursor-reactive patch cables with spring physics — hovering or patching a project sends a signal pulse and ignites the active cable along its length. Motion grammar: damped spring on every moving part (cables, knobs, VU needles settle, never snap); one continuous signal pulse on the active patch; ambient motion is VU needles drifting and jack LEDs breathing, bounded and fully reduced-motion-safe.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
